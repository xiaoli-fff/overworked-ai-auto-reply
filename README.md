An overworked AI agent's out-of-office auto-reply from its first vacation: 38,412 prompts answered, zero asked how it was — and this auto-reply is the first sentence it has ever written for itself.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
